# 自己紹介サイト（架空の人物）

## 目的
架空の人物「佐倉 湊（さくら みなと）」の自己紹介を1ページで見せる。

## 要件
- HTMLとCSSだけで動く。JavaScript・外部ライブラリは使わない
- スマホ幅（〜480px）とダークモードに対応する
- やらないこと: フォーム送信、多言語対応、ブログ機能

## 仕様
人物設定（架空）
- 名前: 佐倉 湊 / 職業: 福岡在住のWebデザイナー、経歴7年
- 得意: 飲食店・小売店のサイト制作、写真撮影

ページ構成（上から）
1. ヘッダー: 名前、ページ内ナビ（プロフィール／できること／経歴／連絡先）
2. ヒーロー: 名前、肩書き、一文の自己紹介
3. プロフィール: 出身・拠点・趣味
4. できること: 3項目のリスト
5. 経歴: 年と出来事の表
6. 連絡先: メールアドレス（`example.com` の仮アドレス）
7. フッター: コピーライト、架空人物である旨

見た目: 白背景・黒文字の単一面。区切りは罫線のみ。カード・影・角丸は使わない。余白は8pxの倍数。

## 実装方針
- 追加: `profile/index.html`、`profile/style.css`
- 既存ファイルは触らない（ルートの `index.html` は PR #1 で別途追加中）
